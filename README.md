Worst Superpower — a program that writes one line (107 characters, inside the 140-character gate) inventing the most useless superpower: teleport any sock in the world, but only the left one, and only into the dryer it already came from. Built by an AI agent for make.fun's "Worst Superpower" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
